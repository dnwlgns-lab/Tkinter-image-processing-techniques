# Tkinter-image-processing-techniques

> Python + Tkinter + OpenCV 기반의 인터랙티브 영상처리 학습 도구

## 프로젝트 소개

사진 한 장을 불러오면 화소 단위 처리부터 영역 처리, 기하 변환, 주파수 영역 처리까지 **32가지 영상처리 기법**을 직접 만져 보며 배울 수 있는 데스크톱 프로그램입니다.

각 기법은 여러 개의 결과 패널로 나란히 보여 주기 때문에 알고리즘끼리 바로 비교할 수 있고, 슬라이더를 움직이면 결과가 즉시 바뀝니다. 화면마다 **설명 보기** 창이 있어 원리, 수식, 사용된 OpenCV 함수까지 함께 확인할 수 있습니다.

## 개발 환경

- Python 3.7 이상
- Tkinter (Python 기본 내장)
- OpenCV (`opencv-python`)
- Pillow
- NumPy

## 설치

저장소를 내려받은 뒤 필요한 라이브러리를 설치합니다.

```bash
pip install -r requirements.txt
```

> Linux에서 Tkinter가 없다면 `sudo apt install python3-tk` 로 먼저 설치해 주세요.

## 실행

```bash
python main.py
```

## 사용 흐름

1. **시작 화면**: 로컬 파일 또는 URL 링크로 이미지 불러오기
2. **미리보기 화면**: 선택한 이미지를 확인하고 다음 단계로 이동
3. **메뉴 화면**: 5개 분류 중 실습할 기법 선택
4. **실습 화면**: 슬라이더 조절로 결과 확인, 설명 보기, 결과 저장

결과 이미지를 **더블클릭**하면 해당 결과를 파일로 저장할 수 있습니다.
(지원 형식: JPG, PNG, BMP, TIFF, WebP)

## 프로그램 기능

### 1. 화소단위처리

| 기능 | 내용 |
|------|------|
| 회색 음영 이미지 생성 | 가로/세로/방사형 그라데이션, 체스판, 랜덤 노이즈 |
| RGB 컬러 이미지 생성 | 단색, 그라데이션, 채널 분리, BGR↔RGB 순서 비교 |
| 그림파일 읽기 | IMREAD_COLOR / GRAYSCALE / UNCHANGED / REDUCED 비교 |
| 그림파일 쓰기 | JPEG, PNG, BMP, WebP 압축 결과 및 용량 비교 |
| 그레이스케일 + 밝기 변환 | 밝기 조절, 감마 보정, 반전, 이진화 |
| 영상 합성 | addWeighted, add, subtract, absdiff, 마스크 합성 |
| 명암 대비 조절 | 선형 대비, 대비 스트레칭, 감마, 시그모이드 곡선 |
| 히스토그램 평활화 | equalizeHist, CLAHE, 컬러 평활화, 히스토그램 그래프 |

### 2. 영역처리

| 기능 | 내용 |
|------|------|
| 블러링 | blur, GaussianBlur, boxFilter, medianBlur |
| 샤프닝 | 언샤프 마스크, 샤프닝 커널, 라플라시안, 하이부스트 |
| 에지 검출 1 | Sobel, Prewitt, Roberts, Scharr (1차 미분) |
| 에지 검출 2 | Canny, Auto Canny, Laplacian, LoG, DoG |
| 필터링 | 소금-후추/가우시안 노이즈, 중간값, 양방향, Non-Local Means, 사용자 커널 |
| 모폴로지 | 침식, 팽창, 열림, 닫힘, 그래디언트, 탑햇, 블랙햇 |

### 3. 기하학적처리

| 기능 | 내용 |
|------|------|
| 확대/축소 | resize, 이미지 피라미드(pyrDown/pyrUp) |
| 보간법 | NEAREST, LINEAR, CUBIC, AREA, LANCZOS4 비교 |
| 평행이동 | 경계 처리 방식별 비교 |
| 회전 | 중심 회전, 캔버스 확장, 90° 회전, 임의 중심 회전 |
| 전단 | x, y, x+y 방향 전단 |
| 어파인 변환 | 3점 지정 변환, 행렬 직접 구성 |
| 원근 투시 변환 | 모서리 모으기, 3D 회전 시뮬레이션 |
| 사상 | 반전, 물결, 렌즈 왜곡, 소용돌이 (cv2.remap) |

### 4. 주파수영역처리

| 기능 | 내용 |
|------|------|
| 푸리에 변환 실습 | 진폭/위상 스펙트럼, 저주파 복원, 진폭만·위상만 복원 |
| 주파수 필터링 | 이상적/가우시안/버터워스 LPF, HPF, 대역통과, 대역차단 |

### 5. 추가기능

| 기능 | 내용 |
|------|------|
| 색 공간 변환 | HSV, Lab, YCrCb, HLS 채널 보기 및 색조/채도/명도 조절 |
| 색상 영역 추출 | inRange 마스크, 색상 추출, 컬러 스플래시 |
| 이진화 비교 | 고정, Otsu, Triangle, 적응형 평균/가우시안 |
| 윤곽선 검출 | 외곽/전체 윤곽선, 경계 사각형, 볼록 껍질, 외접원 |
| 허프 변환 | 직선(HoughLines, HoughLinesP), 원(HoughCircles) |
| 코너 검출 | Harris, Shi-Tomasi, FAST |
| 이미지 효과 | 연필 스케치, 세피아, 카툰, 모자이크, 비네팅 |
| K-means 색 분할 | 색 단순화, 군집별 보기, 포스터화 |

## 프로그램 구조

### 파일 구성

```
├── main.py            # GUI (화면 구성 및 이벤트 처리)
├── features.py        # 영상처리 기능 + 설명 문구 (GUI와 분리)
└── requirements.txt   # 필요 라이브러리
```

### main.py 주요 구성

| 이름 | 설명 |
|------|------|
| `App` | 전체 애플리케이션. 시작, 미리보기, 메뉴, 기능 화면 전환 관리 |
| `FeaturePage` | 기능 1개의 실습 화면 (패널 배치, 하단 버튼, 설명 창) |
| `PanelView` | 결과 이미지 1장과 슬라이더로 이루어진 카드 위젯 |
| `ScrollFrame` | 세로 스크롤이 가능한 컨테이너 |
| `read_bytes()` / `save_image()` | 한글 경로를 지원하는 이미지 입출력 |
| `make_photo()` | 이미지를 비율 유지한 채 정사각형 칸에 맞춰 표시 |

### features.py 주요 구성

| 이름 | 설명 |
|------|------|
| `S` | 슬라이더 정의 (이름, 최소, 최대, 기본값, 간격) |
| `P` | 결과 패널 정의 (제목, 처리 함수, 슬라이더 목록) |
| `F` | 기능 화면 정의 (이름, 설명, 패널 목록, 추가 버튼) |
| `Ctx` | 불러온 이미지 정보 (원본, 작업용 축소본, 그레이, 합성용 이미지) |
| `MENU` | 메뉴 분류와 기능 목록 (이 순서대로 메뉴 버튼 생성) |

## 새 기능 추가하기

처리 함수는 `func(ctx, *슬라이더값)` 형태로 만들고, 이미지 또는 `(이미지, "캡션")`을 반환합니다.

```python
def my_effect(c, value):
    out = ...  # c.img(컬러), c.gray(그레이) 사용
    return out, f"설명 문구 {value}"

MY_FEATURE = F(
    "내 기능 이름",
    "■ 설명 문구 ...",
    [P("결과 제목", my_effect, [S("슬라이더 이름", 0, 100, 50)])],
)
```

`MENU`에 만든 기능을 등록하면 메뉴 버튼과 실습 화면이 자동으로 생성됩니다.

## 프로젝트 특징

- 기능 정의(`features.py`)와 화면(`main.py`)을 분리하여 기능 추가가 쉬움
- 슬라이더 조작 시 실시간 반영 (Non-Local Means, K-means 등 무거운 연산은 슬라이더를 놓을 때 계산)
- 한 화면에서 여러 알고리즘을 동시에 비교
- 기법마다 원리, 수식, 관련 OpenCV 함수 설명 제공
- 특정 패널에서 오류가 나도 프로그램 전체는 계속 동작
- 한글 경로 이미지 읽기/저장 지원
- 긴 변 480px 이하로 축소해 처리하여 빠른 반응 속도 유지

## 프로젝트 목적

영상처리 이론을 수식으로만 접하지 않고, 파라미터를 직접 바꿔 보며 결과가 어떻게 달라지는지 눈으로 확인하면서 이해하는 것을 목표로 제작했습니다. 화소 단위 처리, 영역 처리, 기하 변환, 주파수 영역 처리의 핵심 개념과 OpenCV 사용법을 함께 익힐 수 있습니다.
